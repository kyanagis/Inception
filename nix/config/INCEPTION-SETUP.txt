Inception Universal OVA 利用手順
=================================

このOVAは特定のsubmit commitを内包・固定しません。
通常のsubmit変更ではOVAを作り直さず、実行時にcurrent submitを取得します。

1. 初回OS設定
-------------

OS accountは inception、初期passwordも inception です。
Terminal（Win+Enter）を開き、最初にpasswordを変更してください。

    passwd

42 loginを設定します。

    inception-setup YOUR_42_LOGIN

これにより以下が設定されます。

    /home/YOUR_42_LOGIN/data
    YOUR_42_LOGIN.42.fr
    INCEPTION_LOGIN
    DOMAIN_NAME
    INCEPTION_DATA_DIR

設定後は新しいTerminalを開いてください。

2. current submitを取得・検証
-----------------------------

推奨:

    inception-evaluate --prepare

このcommandは /home/inception/Inception-submit をcloneまたは安全にfast-forwardし、
current submit branchに対してmake configure、make doctor、make checkを実行します。

特定commitへのtest固定はありません。現在使用中のcommitは次で確認できます。

    git -C /home/inception/Inception-submit rev-parse HEAD

3. mandatoryを完全検証
----------------------

    inception-evaluate --mandatory

内部では current submit に対して:

    make configure
    make doctor
    make check
    make up
    make test
    make audit

を実行します。

4. bonusを完全検証
------------------

    inception-evaluate --bonus

または mandatory -> bonus の両方:

    inception-evaluate --full

bonusではRedis、FTPS、Adminer、static site、backupまで実測します。

5. 手動操作
-----------

    cd /home/inception/Inception-submit
    make status
    make logs
    make down

公開OVA内では make host-setup を実行しないでください。
host bootstrapはinception-setupが管理します。

6. host toolのforward compatibility
-----------------------------------

submit branchに .inception/host-tools がある場合、inception-evaluateは各commandを確認します。
OVAにない通常のuserspace commandは対応するnixpkgs packageをephemeral nix shellで補完します。

これによりDockerfile、Compose、script、test、通常のCLI依存追加のためにOVAを再生成する必要はありません。

7. diagnostics
--------------

    inception-audit
    ssh-setup --status

Desktop/TROUBLESHOOTING-QA.txtも参照してください。

submit-onlyの変更はSubmit Compatibility CIで検証され、通常はOVAの再生成を必要としません。
